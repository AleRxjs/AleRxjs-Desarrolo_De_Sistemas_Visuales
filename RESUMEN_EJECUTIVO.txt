🔧 COMANDOS DISPONIBLES
════════════════════════════════════════════════════════════════════════════

Docker Compose:
  $ docker-compose up -d           # Iniciar servicios
  $ docker-compose down            # Detener servicios
  $ docker-compose ps              # Ver estado
  $ docker-compose logs -f         # Ver logs
  $ docker-compose restart         # Reiniciar

Makefile (si tienes make):
  $ make up                        # Iniciar
  $ make down                      # Detener
  $ make logs                      # Ver logs
  $ make install                   # Instalar deps
  $ make help                      # Ver todos

Scripts Interactivos:
  Windows:  manage.bat
  Linux/Mac: ./manage.sh

Acceso a Servicios:
  $ docker-compose exec backend sh         # Shell backend
  $ docker-compose exec frontend sh        # Shell frontend
  $ docker-compose exec mongodb mongosh   # MongoDB shell


✨ CARACTERÍSTICAS DESTACADAS
════════════════════════════════════════════════════════════════════════════

🔄 Hot Reload Development
   Backend: Nodemon recarga automáticamente
   Frontend: Vite HMR en tiempo real
   → Cambios visibles sin reiniciar Docker

📊 Health Checks Automáticos
   MongoDB: Ping cada 10 segundos
   Backend: /api/health cada 30 segundos
   Frontend: HTTP check cada 30 segundos
   → Docker espera a que servicios estén listos

🗄️ Persistencia de Datos
   MongoDB data: Volumen persistente
   → Datos salvos incluso si eliminas contenedor

🌐 Red Aislada
   Servicios se comunican por nombre (DNS)
   Backend accede MongoDB como: mongodb://mongodb:27017
   Frontend accede Backend como: http://backend:5000

🔐 Seguridad
   Usuarios no-root en contenedores
   Variables de entorno para secretos
   .gitignore para proteger credenciales
   CORS configurado
