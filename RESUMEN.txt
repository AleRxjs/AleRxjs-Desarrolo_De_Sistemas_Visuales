⚡ COMANDOS ÚTILES
════════════════════════════════════════════════════════════════════════════

🟢 INICIAR/DETENER
$ docker-compose up -d          # Inicia servicios
$ docker-compose down           # Detiene servicios
$ docker-compose down -v        # Detiene y elimina volúmenes
$ docker-compose restart        # Reinicia servicios

📊 MONITOREO
$ docker-compose ps             # Ver estado de contenedores
$ docker-compose logs -f        # Ver logs en tiempo real
$ docker-compose logs -f backend # Logs solo del backend
$ docker-compose logs -f frontend # Logs solo del frontend

🔧 DESARROLLO
$ docker-compose exec backend sh           # Acceso shell backend
$ docker-compose exec frontend sh          # Acceso shell frontend
$ docker-compose exec mongodb mongosh     # Acceso MongoDB

🧹 LIMPIEZA
$ docker system prune            # Limpiar recursos no usados
$ docker volume ls               # Ver volúmenes
$ docker volume rm nombre        # Eliminar volumen

📈 ESCALABILIDAD
════════════════════════════════════════════════════════════════════════════

Para agregar más servicios (ej: Nginx, Redis):
  1. Agregar en docker-compose.yml
  2. Conectar a la red mern_network
  3. Usar nombres de servicio como DNS

Ejemplo agregando Redis:
  redis:
    image: redis:7-alpine
    networks:
      - mern_network


🔍 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

❌ "Port already in use"
   → Cambiar puerto en docker-compose.yml
   → O detener servicio usando ese puerto

❌ "Cannot connect to MongoDB"
   → Verificar: docker-compose logs mongodb
   → Reiniciar: docker-compose restart mongodb

❌ "Frontend no carga"
   → Verificar backend: curl http://localhost:5000/api/health
   → Ver logs: docker-compose logs frontend

❌ "Cambios no se reflejan"
   → Verificar volúmenes montados en docker-compose.yml
   → Reiniciar servicios: docker-compose restart
